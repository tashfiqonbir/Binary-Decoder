# Binary Encoder & Decoder

A simple, user-friendly Python command-line utility to encode plain text into 8-bit binary code and decode binary code back into human-readable text.

## Features
- **Text to Binary**: Converts alphabets, digits, and special characters into binary format.
- **Binary to Text**: Decodes space-separated or continuous 8-bit binary strings back to ASCII text.
- **Error Handling**: Gracefully handles invalid binary inputs.

## How to Run

1. Make sure you have [Python](https://python.org) installed.
2. Clone the repository:
   ```bash
   git clone https://github.com/Binary-Decoder
   ```
3. Navigate to the project folder:
   ```bash
   cd Binary-Decoder
   ```
4. Run the script:
   ```bash
   python binary_decoder.py
   ```
